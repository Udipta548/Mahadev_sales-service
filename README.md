In this project, I analyzed real-world e-commerce sales data to extract actionable business insights. The workflow included data cleaning, transformation, and modeling, followed by the creation of an interactive Power BI dashboard.

Key insights include:

Sales and profit trends over time

Category and sub-category performance analysis

Customer and region-wise sales distribution

Identification of high-revenue and low-performing products

The dashboard helps business users monitor KPIs and make informed, data-driven decisions.

Skills Demonstrated:
Power BI • Data Analysis • DAX • Data Visualization • Business Insights
